# Decisions

One file per decision that would otherwise be re-litigated: `NNNN-short-slug.md`, holding
Context / Decision / Consequences / Rejected. Append-only — a superseded decision keeps its file
and gains a `Superseded by NNNN` line.

This is repository governance, kept separate from the public CLI documentation in
`docs/` and installed package references in `packages/sync/references/`. The
CHANGELOG says *what* changed, in one line per change; the *why* lives here.
